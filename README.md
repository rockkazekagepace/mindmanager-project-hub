| **Feature** | **Description** |
|:---|:---|
| **Task Linking** | Attach due dates, owners and priorities to any map node as tasks |
| **Gantt Export** | Convert task-enriched maps into interactive Gantt chart views |
| **MS 365 Integration** | Sync tasks, files and contacts from Outlook, Teams and SharePoint |
